Shift Algorithm

The DP compares one number column per series (compare column), within each series's row range. Horizontal column spans describe which contiguous columns belong to that series — on a matched row, all cells in the first-series span copy from that series's source row index, and all cells in the second-series span copy from the other series's row. Other columns fill from the anchored ("later") row. The two spans must not overlap in Excel columns.
